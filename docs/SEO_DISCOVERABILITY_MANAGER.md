# Aloyri Ecommerce SEO & Discoverability Manager

This release adds website-owned SEO operations inside Ecommerce Admin.

- Draft-controlled SEO titles and meta descriptions
- Internal canonical URL controls with validation
- Index/follow controls for public pages and products
- Open Graph and Twitter social metadata
- Dedicated social image uploads
- Search and social preview cards
- SEO health scoring and warnings
- Duplicate title/description detection
- Category, page and product SEO editors
- Versioned 307/308 redirect manager
- Redirect loop, duplicate-source and protected-route safeguards
- Sitemap inclusion driven by published index settings
- Sitemap lastModified based on the published storefront timestamp
- Hard noindex protection for cart, checkout, order confirmation, tracking, return requests and admin
- Product structured data uses current sale pricing and published canonical URLs
- CRM remains authoritative only for price, stock and order operations

All SEO changes use Draft → Preview → Publish → Version History.
